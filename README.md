# Pricing Comparison Table

A simple, unstyled pricing comparison page built with semantic HTML. It presents three subscription plans in an accessible table, using a caption, grouped column headers, and row headers to make plan details easier to understand.

## Features

- Semantic page structure with `<header>`, `<main>`, and `<footer>`
- Accessible comparison table with `<caption>`, `<thead>`, and `<tbody>`
- Scoped row and column headers
- Grouped feature columns using `colspan`
- Responsive viewport metadata

## View the page

Open `index.html` in a web browser. No build tools or dependencies are required.
